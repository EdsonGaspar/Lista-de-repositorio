# Conceito de imutabilidade consiste em não alterar o valor de uma variavel, mais atribuir um novo valor a ela.

## Exemplo

## usuario = ['edson2g', 'hadson2g', 'meu@l']

## novoUsuario = [...usuario, 'novo@t']; Criando assim um novo array com os valores do antigo e um novo valor. Os tres pontos é o operador spread ou spread operator.
